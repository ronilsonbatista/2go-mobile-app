# ADR-002-monorepo: Arquitetura Monorepo

## Status
Aprovado

## Contexto
Uso de Pub Workspaces e Melos para gerenciar apps e packages no mesmo repositório.

## Decisão
Implementar conforme padrões definidos na arquitetura corporativa da 2GO.

## Consequências
- Código limpo, testável e de alta manutenibilidade.
