# ADR-005-bloc-and-cubit: BLoC & Cubit para Gerenciamento de Estado

## Status
Aprovado

## Contexto
Fluxo MVI com BLoC para cenários complexos e Cubit para estados locais.

## Decisão
Implementar conforme padrões definidos na arquitetura corporativa da 2GO.

## Consequências
- Código limpo, testável e de alta manutenibilidade.
